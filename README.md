# Mega zbirka

Збірка для Minecraft 1.21.1 (NeoForge 21.1.264) у форматі [packwiz](https://packwiz.infra.link/).

## Як грати

1. Встановіть [Prism Launcher](https://prismlauncher.org/).
2. Імпортуйте архів «Mega zbirka (Prism)…zip», який вам дав автор збірки: «Додати екземпляр» → «Імпорт».
3. Запускайте як завжди. Перед кожним запуском Prism сам перевіряє цей репозиторій і докачує змінені моди, конфіги та квести. Нічого видаляти чи качати вручну не треба.

Ваші налаштування (`options.txt`, мапа Xaero, Iris) оновлення не перезаписують.

## Для автора

Оновлення публікує `setup-updater/publish.py` з папки екземпляра. Моди з Modrinth і CurseForge зберігаються тут лише посиланнями (`mods/*.pw.toml`). Власні моди збірки та моди без публічного завантаження лежать файлами.
